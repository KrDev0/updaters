Versión 1.3 Build 1 (8 Octubre 2026) 

-	Actualizador con instalador: descarga, verifica y ejecuta el setup automáticamente, sin ZIP ni web
-	Configuración global que sobrevive a cambios de versión (ajustes y lista de descargas ya no se pierden)
-	Binarios de video (yt-dlp/ffmpeg) fuera de Program Files, con migración automática
-	Variantes de video de cualquier web dentro del mismo formulario (MP4 multihilo o HLS)
-	Soporte de cookies para sitios con login y errores explicados (enlace caducado, sesión requerida)
-	Progreso fluido, velocidad y conexiones reales, ventanas que nunca se congelan
-	Filtros del árbol reparados, sin duplicados, iconos .exe originales y borrado definitivo
-	Extensiones de Chrome y Firefox mejoradas (botón sobre el video, menús, selección, sin diálogos dobles)
-	Otras mejoras y correcciones de bugs
-	Para instalar esta actualización es necesario descargar el instalador desde el sitio web (https://kr-dev/?app=pdm)

-	Extensión de Firefox publicada, a la par de Chrome (v1.3.4)
-	Soporte de cookies del navegador para sitios con login y avisos claros si un enlace caduca

-	Progreso fluido 1-2-3, velocidad y conexiones reales, sin congelamientos
